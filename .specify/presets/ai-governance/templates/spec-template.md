## Mandate continuation

Do not copy rules from `constitution/`. Apply `constitution/AI_RULES.md` and
`constitution/AI_ENFORCEMENT.md` §§1.2–1.4.

**Authorized outcome:** [outcome the operator already requested]

**Acceptance observation:** [the result that passes, and one known-bad result]

**Automatic continuation:** continue specify, plan, tasks, and implement
without asking when the mandate already covers this outcome, the next edit
stays inside it, and the step is not merge, push, publish, deploy, or a
change to production data or a shared device.

**Human decision required:** a new objective, an unresolved clarification that
changes scope or authority, a security-sensitive effect, an irreversible or
destructive action, or a plan so incomplete that the next edit would be a
guess. Record the stop. Do not ask between ordinary tasks.

Execution Plan, use the existing plan fields. Do not invent a second schema.
